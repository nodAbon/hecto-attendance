# 월간 근태보고 / 근무일정 설계안

작성일: 2026-06-22

이 문서는 근태보고 페이지의 월 기본 근무일정, 날짜별 조정, 초과근무 계산, 캘린더 표시 규칙을 되돌릴 수 있는 기준점으로 남긴다.

## 1. 목적

- 근태보고 페이지를 단순 출퇴근 조회가 아니라 근무일정 중심의 핵심 관리 화면으로 확장한다.
- 외부사업팀은 근무일정을 기준으로 출퇴근과 초과근무를 계산한다.
- 다른 부서는 기존 출퇴근 중심 UX를 유지한다.
- 월 기본 일정과 날짜별 조정을 분리해 관리한다.

## 2. 적용 범위

### 2.1 외부사업팀

- 사업개발팀, 사업관리1~3팀을 외부사업팀으로 본다.
- 외부사업팀의 기본 근무일정은 평일 `10:00-19:00`이다.
- 날짜별로 근무일정 조정이 가능하다.
- 초과근무 계산은 외부사업팀에만 적용한다.

### 2.2 그 외 부서

- 기존처럼 출퇴근 중심으로 표시한다.
- 근무일정은 보이되, 외부사업팀만큼 강한 일정 관리 UX를 적용하지 않는다.

## 3. 핵심 규칙

### 3.1 월 기본 근무일정

- 월 기본 근무일정은 해당 월의 기본 베이스값이다.
- 기본값은 다음 달로 이어진다.
- 기본값이 바뀌면 다음 달도 그 값을 초기값으로 사용한다.
- 단, 이미 날짜별로 조정된 날짜는 월 기본값 변경의 영향을 받지 않는다.

### 3.2 날짜별 조정

- 날짜별 조정은 월 기본과 별도의 고정값이다.
- 조정된 날짜는 월 기본값과 무관하게 유지된다.
- 캘린더에서는 날짜 아래에 `10:00-18:00` 형식으로 표시한다.
- 조정된 날짜는 별도의 `조정` 뱃지보다 조정된 시간 자체를 보여준다.

### 3.3 근무일정 없음

- 근무일정 삭제는 해당 날짜를 완전한 `근무일정 없음` 상태로 만든다.
- `근무일정 없음`은 비근무로 본다.
- 출퇴근 기록이 있더라도 화면에는 기록을 보여줄 수 있지만, 합산과 초과근무 계산에는 반영하지 않는다.
- 빈 일정 셀은 배경만으로 더 어둡게 구분한다.

### 3.4 초과근무 계산

- 초과근무는 외부사업팀만 계산한다.
- 초과근무는 반드시 근무일정 종료 시각 이후를 기준으로 한다.
- 출근이 빨라도 초과근무 계산에는 영향을 주지 않는다.
- 지각은 초과근무에 영향을 주지 않는다.
- 근무일정이 없는 날은 초과근무 계산 대상이 아니다.
- 초과근무 허용이 체크된 경우에만 계산한다.
- 계산 단위는 30분이다.
  - 29분 = 0
  - 30분 = 0.5
  - 59분 = 0.5
  - 60분 = 1.0

### 3.5 초과근무 허용

- 초과근무 허용은 월 기본에도 저장한다.
- 날짜별 조정에서도 개별 해제가 가능하다.
- 월 기본 허용이 `true`이면 기본적으로 허용 상태로 본다.
- 개별 날짜에서 비허용으로 바꾸면 그 날짜만 계산에서 제외한다.

## 4. 캘린더 표시 규칙

### 4.1 월 검색

- 공통 `MonthSearchPicker`를 사용한다.
- 직접 타이핑, 자동완성 목록, 좌우 이동 버튼을 함께 유지한다.

### 4.2 셀 표시

- 조정된 날짜는 날짜 아래에 조정된 근무시간을 보여준다.
- 실제 출퇴근은 그 아래에 2줄까지 보여준다.
- 출퇴근 기록이 없는 날은 `-` 같은 텍스트를 표시하지 않는다.
- 휴가는 이름으로 표시한다.
- 휴가명은 휴가 유형 원문을 우선한다.

### 4.3 빈 일정 셀

- 근무일정이 없는 셀은 배경색으로 어둡게 구분한다.
- 텍스트는 최소화한다.

## 5. 우측 패널 UX

- 우측 패널에서 다중 선택을 지원한다.
- 버튼 및 동작은 같은 패널에서 처리한다.
- 생성
  - 비어 있는 날짜에만 일정 생성
  - 사용자가 선택한 출근/퇴근 시간과 초과근무 허용 값을 저장
- 삭제
  - 선택한 날짜를 완전한 `근무일정 없음`으로 변경
- 복원
  - 해당 날짜를 월 기본 근무일정으로 되돌림
- 다중 선택한 날짜도 동일한 버튼 체계에서 처리한다.

## 6. 데이터 구조 기준

### 6.1 월 기본

- `sa_employee_schedules`
- 직원별 기본 근무 시작/종료를 저장한다.
- 새 달을 열 때 이 값을 초기값으로 사용한다.

### 6.2 날짜별 조정

- `sa_schedule_overrides`
- `emp_no`, `work_date` 기준으로 1건씩 관리한다.
- `schedule_start`, `schedule_end`, `allow_overtime`, `note`를 저장한다.

### 6.3 근무일정 없음

- 날짜별 조정을 삭제하면 그 날짜는 비근무 상태로 간주한다.

## 7. 구현 우선순위

1. 월 기본 일정과 날짜별 조정의 우선순위 분리
2. 근무일정 없음 상태 구분
3. 초과근무 계산 정리
4. 캘린더 셀 표시 정리
5. 우측 패널 생성/삭제/복원 통합
6. 외부사업팀만 특수 규칙 적용
7. 다른 부서는 기존 출퇴근 중심 유지

## 8. 롤백 기준

- 캘린더가 깨지면 이 문서의 규칙을 기준으로 되돌린다.
- 다음 항목은 반드시 유지한다.
  - 월 기본과 날짜별 조정 분리
  - 초과근무는 외부사업팀만
  - 근무일정 없음은 비근무
  - 조정된 날짜는 시간 자체를 보여줌
  - 휴가는 이름으로 표시
